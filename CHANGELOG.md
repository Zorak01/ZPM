# Changelog

## 0.1.0 - Unreleased

- Blender-independent typed mesh API and validated binary file I/O.
- Exact Float32 positions and ordered vertex, face and edge topology.
- Raw32 and compact aligned storage profiles.
- Blender import/export with mixed polygons, loose edges and nonmanifold meshes.
- Codec and real Blender round-trip tests.
- Public reference-codec benchmarks, fixtures and reproduction tools.

The ZMC1 packet envelope is experimental, not a stable final ZPM format.
